Dictionnaires

La clé est le libellé. La valeur est la chaîne réutilisée.

Réglages → Dictionnaires. Une action peut prendre une entrée fixe, parmi une sélection (jusqu’à 5), ou demander à chaque envoi.

Nom de raccourci

La valeur est le nom exact du raccourci, tel qu’il apparaît dans l’app Raccourcis. Le texte de la note est envoyé à part. Un jeton comme {{title}} reste du texte dans ce nom : il n’est pas remplacé.

Gabarit d’URL

Pour l’action Lien. À l’envoi, Tetis remplace ces quatre jetons dans la valeur :

Jeton Texte inséré
{{title}} Ligne 1
{{body}} Lignes suivantes
{{raw}} Texte entier
{{createdAt}} Date de la note

Exemple : https://example.com/search?q={{title}}

Things

L’action Things crée la tâche. Collez le lien copié dans Things (Partager → Copier le lien). Jusqu’à 5 endroits avec « Parmi une sélection ». L’inbox Things n’a pas besoin de lien.

L’action Lien ouvre l’URL telle quelle. Un lien things:///show?id=… affiche le projet ou l’inbox. La note n’y est pas ajoutée.

Pour créer la tâche depuis un dictionnaire, la valeur est un gabarit add. L’identifiant est la partie après id= dans le lien copié.

things:///add?title={{title}}&notes={{body}}&list-id=IDENTIFIANT

Inbox, sans projet : things:///add?title={{title}}&notes={{body}}

Webhook

La valeur peut être du texte ou du JSON. Les quatre jetons sont remplacés de la même façon. L’action choisit ce qui part : la note seule, la valeur seule, ou les deux.
